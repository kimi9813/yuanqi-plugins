# yuanqi-plugins 手机部署教程（纯文本版）

> 本教程专门用手机浏览器操作编写，不需要安装任何电脑软件，也不需要命令行。
> 推荐平台：**Render（免费、有网页后台、操作最简单）**。
>
> 如果你希望使用「函数计算」（Serverless / FaaS）方式部署，请直接跳到「方案 D：阿里云函数计算 FC」。
> 函数计算优点：按调用次数计费、不用维护服务器、国内访问快；缺点：实例无状态，文件/任务数据会随实例回收丢失。

---

## 一、准备工作

### 1.1 你需要什么

1. 一部能上网的智能手机。
2. 一个 **GitHub 账号**（如果没有，用手机浏览器打开 github.com 注册）。
3. 一个 **腾讯元器账号**（如果没有，用手机微信或 QQ 登录 yuanqi.tencent.com）。
4. 本项目的 GitHub 仓库地址：
   ```
   https://github.com/kimi9813/yuanqi-plugins
   ```

### 1.2 建议使用的手机浏览器

- **Chrome（安卓）** 或 **Safari（苹果）**。
- 建议开启「桌面版网站」模式，方便查看 GitHub 后台完整界面。
  - Chrome：点击右上角三个点 → 勾选「桌面版网站」。
  - Safari：点击地址栏左侧的「大小」→ 请求桌面网站。

## 二、方案 A：Render 部署（推荐，免费）

Render 是一个免费的云平台，可以直接从 GitHub 仓库部署网站，全程在手机上用浏览器完成。

### 2.1 注册 Render 账号

1. 用手机浏览器打开：
   ```
   https://dashboard.render.com/
   ```
2. 点击页面上的 **Sign Up** 或 **Get Started**。
3. 选择 **Sign up with GitHub**（用 GitHub 账号登录）。
4. 按提示授权 Render 访问你的 GitHub 仓库。

### 2.2 创建 Web Service

1. 登录 Render 后，点击右上角 **New** 按钮。
2. 选择 **Web Service**。
3. 在 GitHub 仓库列表中找到并点击 **kimi9813/yuanqi-plugins**。
   - 如果找不到，点击页面上的 **Configure account** 或 **+ Connect account**，授权 Render 访问该仓库。
4. 进入配置页面，填写以下信息：

| 配置项 | 填写内容 |
|--------|----------|
| Name | `yuanqi-plugins`（也可以自己取） |
| Region | 选择 **Singapore (Asia Pacific)**，离中国最近 |
| Branch | `master` |
| Runtime | `Python 3` |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn app:app --host 0.0.0.0 --port 10000` |
| Plan | 选择 **Free** |

5. 页面下方点击 **Advanced** 展开高级设置：
   - 添加环境变量：
     - Key：`PORT`
     - Value：`10000`
6. 点击页面最下方的 **Create Web Service**。

### 2.3 等待部署完成

1. Render 会自动下载代码、安装依赖、启动服务。
2. 等待页面显示 **Your service is live** 或绿色状态 **Live**。
3. 页面顶部会显示你的公网地址，例如：
   ```
   https://yuanqi-plugins-xxx.onrender.com
   ```
   把这个地址复制下来，后面要用。

### 2.4 挂载磁盘（重要）

为了让文件上传、技能、任务数据不被清空，需要挂载磁盘：

1. 在 Render 后台，点击你的服务 **yuanqi-plugins**。
2. 左侧菜单点击 **Disks**。
3. 点击 **Add Disk**。
4. 填写：
   - Name：`data`
   - Mount Path：`/app/data`
   - Size：拖动到 `1 GB`（免费最大 1GB）
5. 点击 **Save**。
6. Render 会自动重启服务，等待状态重新变为 Live。

## 三、方案 B：Railway 部署（备选）

Railway 也是一个云平台，操作比 Render 更简单，但免费额度有限。

### 3.1 注册 Railway

1. 打开：
   ```
   https://railway.app/
   ```
2. 点击 **Start a New Project** 或 **Login**。
3. 选择用 GitHub 登录。

### 3.2 部署项目

1. 登录后点击 **New Project**。
2. 选择 **Deploy from GitHub repo**。
3. 选择 **kimi9813/yuanqi-plugins**。
4. Railway 会自动读取项目里的 `railway.json` 配置并部署。
5. 等待部署完成，会生成类似：
   ```
   https://yuanqi-plugins.up.railway.app
   ```
   复制这个地址。

### 3.3 添加环境变量

1. 点击项目中的 **yuanqi-plugins** 服务。
2. 选择 **Variables** 标签。
3. 点击 **New Variable**。
4. 填写：
   - Name：`PORT`
   - Value：`8000`
5. 保存后 Railway 会自动重新部署。

## 四、方案 C：GitHub Codespaces 部署（临时测试）

适合临时给腾讯元器测试用，不需要第三方平台。

### 4.1 创建 Codespace

1. 用手机浏览器打开项目仓库：
   ```
   https://github.com/kimi9813/yuanqi-plugins
   ```
2. 点击绿色的 **Code** 按钮。
3. 切换到 **Codespaces** 标签。
4. 点击 **Create codespace on master**。
5. 等待 1-3 分钟，浏览器会打开一个 VS Code 网页版。

### 4.2 启动服务

1. 在屏幕下方找到终端（如果没有，点击底部菜单的 **Terminal** → **New Terminal**）。
2. 在终端中输入并回车：
   ```bash
   pip install -r requirements.txt
   ```
3. 等待安装完成，再输入：
   ```bash
   python app.py
   ```
4. 当看到类似下面提示时，服务已启动：
   ```
   Uvicorn running on http://0.0.0.0:8000
   ```

### 4.3 转发端口并公开

1. 点击底部菜单的 **Ports**（端口）。
2. 找到 **8000** 端口，点击它。
3. 点击右键菜单（或长按）→ **Port Visibility** → **Public**。
4. 复制生成的地址，例如：
   ```
   https://xxx-8000.app.github.dev
   ```

> 注意：Codespaces 关闭后地址会变，只适合临时测试。

## 五、方案 D：阿里云函数计算 FC（函数计算，国内访问快）

阿里云函数计算 FC 适合希望按调用付费、不需要长期开机的场景。手机上主要用阿里云 App 或手机浏览器操作。

### 5.1 准备工作

1. 注册阿里云账号并完成实名认证。
2. 开通「函数计算 FC」服务：
   ```
   https://fc.console.aliyun.com/
   ```
3. 记住你的账号 ID，后面会用到。

### 5.2 创建函数（手机浏览器版）

1. 用手机浏览器打开阿里云函数计算控制台：
   ```
   https://fc.console.aliyun.com/
   ```
2. 建议开启「桌面版网站」模式。
3. 点击左侧菜单 **函数**，然后点击 **创建函数**。
4. 选择 **使用模板创建** 或 **使用自定义运行时创建**。这里选择 **自定义创建**：
   - 函数类型：**HTTP 函数**
   - 函数名称：`yuanqi-plugins`
   - 运行环境：**Python 3.11**
   - 请求处理程序（Handler）：`handler`
5. 高级配置：
   - 内存规格：**1024 MB**（文件转换需要较大内存）
   - 超时时间：**60 秒**
   - 实例并发度：**100**
6. 点击 **创建**。

### 5.3 上传代码

阿里云 FC 支持直接上传 ZIP 包或绑定 GitHub。手机上最方便的是 ZIP 上传：

1. 在 GitHub 仓库页面，点击绿色的 **Code** 按钮。
2. 点击 **Download ZIP**，把项目 ZIP 下载到手机。
3. 回到阿里云 FC 函数详情页，点击 **代码** 标签。
4. 点击 **上传代码**，选择刚才下载的 `yuanqi-plugins-master.zip`。
5. 等待上传完成，FC 会自动解压。

> 注意：ZIP 包里项目根目录可能是 `yuanqi-plugins-master/`，需要把里面文件移到函数根目录。如果不会操作，建议在电脑上解压后重新打包，或直接使用 Render/Railway。

### 5.4 配置触发器

1. 在函数详情页，点击 **触发器** 标签。
2. 点击 **创建触发器**。
3. 选择 **HTTP 触发器**：
   - 触发器名称：`http`
   - 请求方法：勾选 **GET、POST、PUT、DELETE、OPTIONS**
   - 认证方式：**无需认证**
4. 点击 **创建**。
5. 创建完成后会显示公网访问地址，例如：
   ```
   https://yuanqi-plugins-xxx.cn-hangzhou.fcapp.run
   ```
   复制这个地址。

### 5.5 测试函数

1. 用手机浏览器访问：
   ```
   https://你的地址/health
   ```
2. 如果返回 `{"status":"ok"}`，说明函数运行正常。

## 六、方案 E：腾讯云云函数 SCF（函数计算）

腾讯云 SCF 也支持本项目，但需要配置 API 网关触发器。

### 6.1 创建函数

1. 打开腾讯云 SCF 控制台：
   ```
   https://console.cloud.tencent.com/scf
   ```
2. 点击 **新建**。
3. 选择 **从头开始**：
   - 函数名称：`yuanqi-plugins`
   - 运行环境：**Python 3.11**
   - 执行方法：`handler.main_handler`
4. 点击 **完成**。

### 6.2 上传代码

1. 在 GitHub 下载项目 ZIP 包（同 5.3 节）。
2. 进入 SCF 函数代码页，点击 **上传** → **本地上传 ZIP 包**。
3. 选择下载的 ZIP 文件上传。

### 6.3 配置 API 网关触发器

1. 点击 **触发管理** 标签。
2. 点击 **创建触发器**。
3. 触发方式选择 **API 网关**。
4. 选择 **新建 API 服务**，服务名填 `yuanqi-plugins-api`。
5. 发布环境选择 **发布**。
6. 请求方法选择 **ANY**。
7. 点击 **提交**。
8. 创建完成后会显示访问路径，例如：
   ```
   https://service-xxx.gz.apigw.tencentcs.com/release/
   ```
   复制这个地址。

## 七、修改 OpenAPI 规范文件

部署完成后，需要把 `specs/*.yaml` 里的 `servers.url` 改成你的公网地址。

### 7.1 在手机上编辑 YAML

以 Render 为例，假设你的地址是：
```
https://yuanqi-plugins-xxx.onrender.com
```

1. 用手机浏览器打开 GitHub 仓库：
   ```
   https://github.com/kimi9813/yuanqi-plugins
   ```
2. 进入 `specs` 文件夹。
3. 逐个打开以下 5 个文件：
   - `web_tool_openapi.yaml`
   - `file_tool_openapi.yaml`
   - `terminal_tool_openapi.yaml`
   - `skill_tool_openapi.yaml`
   - `agent_task_openapi.yaml`
4. 点击文件右上角的 **铅笔图标**（Edit this file）。
5. 找到类似下面的内容：
   ```yaml
   servers:
     - url: http://localhost:8000/web
   ```
6. 把它改成你的公网地址 + 对应前缀：
   - `web_tool_openapi.yaml`：
     ```yaml
     servers:
       - url: https://yuanqi-plugins-xxx.onrender.com/web
     ```
   - `file_tool_openapi.yaml`：
     ```yaml
     servers:
       - url: https://yuanqi-plugins-xxx.onrender.com/file
     ```
   - `terminal_tool_openapi.yaml`：
     ```yaml
     servers:
       - url: https://yuanqi-plugins-xxx.onrender.com/terminal
     ```
   - `skill_tool_openapi.yaml`：
     ```yaml
     servers:
       - url: https://yuanqi-plugins-xxx.onrender.com/skill
     ```
   - `agent_task_openapi.yaml`：
     ```yaml
     servers:
       - url: https://yuanqi-plugins-xxx.onrender.com/agent
     ```
7. 修改完成后，滑动到页面最下方，填写提交信息：
   - Commit message：`update servers url`
   - 选择 **Commit directly to the master branch**。
8. 点击 **Commit changes**。

> 提示：如果你的部署地址是 Codespaces 的 `https://xxx-8000.app.github.dev`，同样方法替换即可。

## 八、注册到腾讯元器插件中心

### 8.1 进入插件中心

1. 用手机浏览器打开：
   ```
   https://yuanqi.tencent.com/
   ```
2. 用微信/QQ 登录。
3. 进入「插件中心」或「我的插件」。
4. 点击「创建插件」或「新建插件」。

### 8.2 选择 OpenAPI 插件

1. 选择插件类型为 **OpenAPI 插件**。
2. 上传 YAML 文件。
   - 手机上传 YAML：可以在 GitHub 上打开对应 YAML 文件，点击 **Raw** 按钮，全选复制内容，然后粘贴到元器的文本框中；或者下载 YAML 文件后上传。
3. 元器会自动解析 YAML，显示出该插件包含的工具（operationId）。

### 8.3 配置插件信息

每个 YAML 对应一个插件，需要填写：

| 项目 | 建议填写 |
|------|----------|
| 插件名称 | 网页工具 / 文件工具 / 终端工具 / 技能工具 / Agent任务管理 |
| 插件描述 | 参考 YAML 中 info.description 的内容 |
| 图标 | 可任意选择 |
| 工具列表 | 保持默认，元器会自动读取 |

1. 填写完成后点击「保存」或「发布」。
2. 依次上传 5 个 YAML 文件，完成 5 个插件的注册。

## 十、常见问题（手机操作版）

### Q1：Render 部署后状态一直是 "Deploying" 怎么办？

- 免费实例启动需要 2-5 分钟，请耐心等待。
- 如果超过 10 分钟还是失败，点击 Render 后台的 **Logs** 查看错误日志。
- 常见原因：Build Command 或 Start Command 填错了，请对照教程检查。

### Q2：元器提示 "servers.url 不可达" 怎么办？

- 确认 `specs/*.yaml` 中的地址是 `https://` 开头。
- 确认地址末尾没有多余斜杠，例如不要写成 `/web/`。
- 在手机上直接访问该地址 + `/health`，看是否能打开。

### Q3：文件上传后找不到了？

- Render 需要挂载 Disk，否则每次重启数据都会丢失。请按 2.4 节操作。
- Railway 免费实例也会周期性重启，建议只用于测试。

### Q4：手机上怎么复制 YAML 的 Raw 内容？

1. 在 GitHub 打开 YAML 文件。
2. 点击右上角 **Raw**。
3. 长按页面内容，选择「全选」→「复制」。
4. 回到元器粘贴即可。

### Q5：部署完成后想更新代码怎么办？

- Render/Railway 会自动检测 GitHub 仓库的修改并重新部署。
- 函数计算平台需要重新上传 ZIP 包或使用 Serverless Devs 命令行重新部署。
- 你只需要在 GitHub 上修改代码，保存后会自动同步到 Render/Railway。

### Q6：函数计算部署后文件/任务数据丢失？

- 这是正常的。函数计算实例是无状态的，每次冷启动或实例回收后本地数据会清空。
- 如果只是给元器测试用，不影响使用。
- 如果需要持久化，阿里云 FC 可挂载 NAS，腾讯云 SCF 可挂载 CFS。

### Q7：函数计算返回 502 错误？

- 超时时间设置太短，建议在平台后台改为 30-60 秒。
- 内存不足，文件转换等操作建议设置为 1024 MB。

## 十一、总结

1. **最简单的路径**：Render 注册 → 创建 Web Service → 挂载 Disk → 复制公网地址。
2. **国内访问快**：阿里云函数计算 FC 或腾讯云 SCF（函数计算）。
3. **必须修改**：`specs/*.yaml` 中的 `servers.url`。
4. **最后一步**：在腾讯元器插件中心上传 5 个 YAML 文件。
5. **验证**：访问 `/health`，在元器中发送测试消息。

如果你在手机上操作遇到困难，建议优先使用 **Render + 桌面版网站** 组合，成功率最高。函数计算更适合有阿里云/腾讯云基础的用户。
